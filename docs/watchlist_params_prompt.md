# Watchlist 可選參數 Prompt

把下面「Prompt」整段複製給**另一個可上網的 AI**（ChatGPT / Claude / Gemini 等），再把你目前的 `config/watchlist.txt` **貼在 Prompt 後面**。

本檔只給人用，**不要**讓本倉庫的自動化去改 `watchlist.txt`。產出請你自己覆核後再貼回清單。

---

## Prompt（從此行複製到「請把 watchlist.txt 貼在下面」為止）

你是價值投資研究助理。請幫我檢查並**僅在有把握時**為觀察清單補上可選參數。

### 這套系統在算什麼

這是港股／A 股／美股的內在價值系統：財報進八個估值模型，依公司**畫像**加權得到 IV 與 P25–P75；再用資料日股價 ÷ IV 切五檔區間（非常便宜／便宜／合理／昂貴／非常昂貴）。安全邊際 MOS 只影響「安全買點 = IV × (1−MOS)」，**不改**五檔切點。

`watchlist.txt` 每一行是：`代號  [key=value ...]  # 繁中註解`  
區段：`[HK]` 港股、`[CN]` A 股、`[US]` 美股。`#` 後面是註解。

### 可選參數（全部為手動覆寫；不寫則系統自動推導）

只允許使用這些 key：`profile`、`beta`、`mos`、`note`。  
**預設不要填** `shares=`、`ccy=`（股數與交易幣別系統會處理；只有股數明顯錯、或極少見的幣別例外才考慮，這次請省略）。

| 參數 | 何時才覆寫 | 何時不要寫 |
|---|---|---|
| `profile=financial` / `growth` / `mature` / `loss_making` | 銀行、保險、券商等，FCFF 幾乎無意義時，**強烈建議** `profile=financial`。行業名稱含「银行／保险／Bank／Insur」系統也會自動判 financial。 | **不要**把支付網路（Visa、Mastercard）、醫療保險／健康管理（如 UNH）、鐵塔、公用事業（電力／燃氣／水務）標成 `financial`。這些不是銀行帳本，應讓系統走成熟／公用 β，必要時可標 `profile=mature`。不確定就省略。 |
| `beta=1.05` | 系統性風險明顯高於／低於同行：高槓桿互聯網、新股、半導體可偏高（如 1.15–1.25）；公用、電訊、穩健能源可偏低（如 0.70–0.85）。 | 普通大型成熟股、你沒有把握時**不要填**。系統會用行業表或預設 1.00。 |
| `mos=0.35` | 地產、週期、槓桿偏高、你想更保守才覆寫（全域已是 25%）。 | 大多數核心持股用全域即可，不要每檔都填。 |
| `note=核心持股` | 純標籤，不參與計算。可用簡短繁中（如 `note=波克夏`、`note=新股`）。 | 沒有額外資訊就省略。 |

### 請你上網查、再決定要不要標

對每一檔查近期公開資訊（上市／行業／槓桿／波動），但：

- **不適合就省略**，寧缺勿濫。不要為了「看起來完整」而填。
- 不要發明系統沒有的 key。
- 不要改區段標題、不要刪股票、不要新增股票，除非我另外要求。
- 已有參數若仍然合理，請保留；只有明顯過時或錯誤才改。
- 註解用**繁體中文**，保持 `# 公司簡稱` 風格。

### 輸出格式

只輸出可直接貼回 `watchlist.txt` 的完整檔案內容：

- 保留檔頭說明與 `[HK]` / `[CN]` / `[US]`
- 參數之間一個空白，例如：`00005   profile=financial  # 匯豐控股`
- 多個參數：`BRK.B   profile=financial  note=波克夏`
- 不要 markdown 圍欄，不要解釋段落。若有改動摘要，用檔案最上方的 `#` 註解寫三行以內即可。
